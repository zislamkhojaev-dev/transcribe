# Расшифровка интервью

Локальная расшифровка русских записей интервью в один текстовый файл. Фразы идут в том порядке, в каком они звучат в записи. Аудио и текст не отправляются в интернет: модели качаются один раз и дальше работают на этом компьютере.

Подходит для длинных разговоров, по которым потом описывают бизнес-процесс. Это дословная расшифровка, не краткое содержание и не пересказ.

## Что нужно заранее

- macOS на Apple Silicon (проверялось на MacBook M1 Pro)
- Python 3.11
- [ffmpeg](https://ffmpeg.org/) в `PATH`

```bash
brew install ffmpeg
brew install python@3.11
```

## Установка

В каталоге проекта:

```bash
/opt/homebrew/bin/python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

Дальше команды можно запускать и без `activate`, через `.venv/bin/python`.

Первый запуск скачает модель речи [ai-sage/GigaAM-v3](https://huggingface.co/ai-sage/GigaAM-v3) (ревизия `e2e_rnnt`) в `.cache/huggingface`. Это несколько сотен мегабайт и нужен интернет. Когда веса уже лежат в кэше, расшифровка идёт офлайн.

## Как это устроено

1. `ffmpeg` приводит запись к одному каналу, 16 кГц.
2. Silero VAD находит речь и режет длинный файл на куски короче 25 секунд. Так устроена модель GigaAM.
3. GigaAM распознаёт каждый кусок и ставит время на слова.
4. Слова собираются во фразы по паузам около 0.7 секунды. Порядок строк совпадает с записью.
5. Если включены говорящие, pyannote размечает, кто когда говорил, и к фразе добавляется `Спикер 1`, `Спикер 2` и так далее. Это анонимные метки по голосу в этой записи, не имена людей.

Числа и даты модель может записать в письменном виде: «ста тысяч» станет «100 000». Смысл и порядок фраз при этом не переписываются. Редкие названия систем и коды она может расслышать неверно. Таймкод нужен, чтобы вернуться к этому месту в аудио.

## Командная строка

```bash
.venv/bin/python -m transcribe_app путь/к/интервью.m4a -o расшифровка.txt
```

Без `-o` текст сохранится рядом с исходником, с тем же именем и расширением `.txt`. Подходят аудио и видео, которые читает ffmpeg: `m4a`, `mp3`, `wav`, `mp4` и другие.

В терминале видно ход работы: преобразование, число фрагментов, какой фрагмент распознаётся сейчас.

Таймкоды включены по умолчанию. Убрать их:

```bash
.venv/bin/python -m transcribe_app интервью.m4a -o расшифровка.txt --no-timestamps
```

Говорящие:

```bash
.venv/bin/python -m transcribe_app интервью.m4a -o расшифровка.txt --diarize
```

Принудительно считать на процессоре, а не на видеочипе Mac:

```bash
.venv/bin/python -m transcribe_app интервью.m4a -o расшифровка.txt --device cpu
```

По умолчанию используется MPS, если он есть. Иначе CPU. То же самое можно задать переменной `TRANSCRIBE_DEVICE=cpu` или `TRANSCRIBE_DEVICE=mps`.

## Веб-страница

Только на этом компьютере, без публичной ссылки:

```bash
.venv/bin/python -m transcribe_app --ui
```

Откройте http://127.0.0.1:7860

Загрузите запись, при желании включите «Определять говорящих» и «Таймкоды», нажмите «Расшифровать». Текст появится на странице, тот же файл можно скачать. Копия лежит в `.cache/outputs/`.

Если токена Hugging Face нет, переключатель говорящих выключен. Расшифровка без меток при этом работает.

## Как выглядит результат

С таймкодами:

```text
[00:12:03.420] Сначала заявка падает в очередь согласования.
[00:12:11.080] Если сумма больше 100 тысяч, её смотрит финансовый контролёр.
```

Со спикерами:

```text
[00:12:03.420] Спикер 1: Сначала заявка падает в очередь согласования.
[00:12:11.080] Спикер 2: Если сумма больше 100 тысяч, её смотрит финансовый контролёр.
```

Без таймкодов в файле остаются только строки текста, в том же порядке.

Время в скобках — начало фразы от начала записи: `часы:минуты:секунды.миллисекунды`.

## Говорящие

Базовая расшифровка токен не требует. Метки спикеров требуют один раз:

1. Аккаунт на [Hugging Face](https://huggingface.co/).
2. Принять условия модели [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1).
3. Создать read-токен и положить его в `.env` в корне проекта:

```text
HF_TOKEN=hf_...
```

Образец есть в `.env.example`. Файл `.env` в git не попадает.

Токен нужен только чтобы скачать веса диаризации. После этого можно работать без сети, как и с моделью речи.

## Что не уходит в git и в сеть

| Каталог или файл | Зачем |
| --- | --- |
| `.venv/` | установленные библиотеки |
| `.cache/huggingface/` | скачанные модели |
| `.cache/outputs/` | готовые TXT из веб-страницы |
| `.env` | токен Hugging Face |

Их можно удалить. Модели при следующем запуске скачаются снова, если есть интернет.
